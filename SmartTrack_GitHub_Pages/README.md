# SmartTrack – GitHub Pages Frontend

SmartTrack is a front-end preview of a sales, inventory, cashflow, and customer credit management system designed for small retail stores.

## Technologies
- HTML5 – page structure
- CSS3 – layout and responsive styling
- JavaScript – demo interactions and navigation
- GitHub Pages – static website hosting

## Pages
- `index.html` – Login preview
- `dashboard.html` – Dashboard
- `cashflow.html` – Cashflow (In/Out)
- `inventory.html` – Inventory & Assets
- `credit.html` – Store Credit (Utang)
- `reports.html` – Reports
- `settings.html` – Settings

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload all files and folders from this project. Keep the folder structure intact.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish. Open the website URL shown on the Pages settings screen.

## Important
This is a static front-end prototype. It uses sample data and demo interactions only. GitHub Pages does not execute PHP, so this version uses HTML, CSS, and JavaScript. Login is a visual demo and does not authenticate users. Forms do not save records. A PHP-compatible hosting service and backend/database implementation will be needed for real authentication and persistent data.
